# Dress-up game image sources and prompts

Images were prepared with the built-in imagegen tool from the user-supplied ROSAZZING paper-doll references. Original generated RGBA files are preserved; SVG clipping and per-item anchors position the parts in the game.

Final assets: `static/dressup/{chacha,shasha,saekom,banjjak,hachoo,yeou,kkang,ballet,yogu,pudding,dalkom,village}.png`.

The catalog contains source rectangles and individual fitting coordinates. Village resident snapshots are stored in SQLite; draft outfits remain in the browser. Each character has one resident; sending it again updates its clothing.
